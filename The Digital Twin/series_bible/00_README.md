# Brave New Times: series bible

Lothar J. Musiol writing as Rob O. Taylor. British deadpan near-future satire. Reuse this folder for every book in the series; it is the single source of truth.

## Files
- `01_series_plan.md`: premise, market and spelling decisions, voice rules, series shape, Subject 2 decision, back-matter plan.
- `02_characters_and_places.md`: looks, voice, smell, taste, touch and character of every person and place. Update the same day a chapter adds a detail.
- `../notes/book1_continuity.md`: what has actually happened on the page in Book 1 (facts, running gags, seeds). Each later book gets its own `bookN_continuity.md`.

## How to use
1. Before writing: read 00, 01, 02, then the current book's continuity file.
2. While writing: new person, place, or sensory detail goes into 02 at once; new plot fact goes into the book's continuity file.
3. A trait in 02 never changes between books unless the story changes it on the page and the bible says so.
4. No sentence recurs within a book; callbacks vary the wording.
5. Obey `notes/LOTHAR_RULES.md` at the repo root (including the banned-name search before every commit).
