H1: Chapter 28 — Nodal Analysis
P: Faced with a tangle of resistors and sources, nodal analysis gives you a recipe that always works: label the node voltages, write KCL at each node, solve. It is also, in essence, what a SPICE simulator does, so knowing it tells you when a simulation has been set up wrong.
P: Where you meet this: Circuit simulators (which use modified nodal analysis), op-amp circuit analysis, and bias calculations.
H2: 28.1 The Idea Behind Nodal Analysis
P: Series/parallel reduction (Chapter 27) fails as soon as a circuit contains a configuration where no two resistors are purely in series or purely in parallel with each other — a bridge circuit is the classic example. Nodal analysis is the first of two systematic methods (mesh analysis, Chapter 29, is the second) that handles any resistive circuit whatsoever, however tangled its topology, by turning the circuit into a system of simultaneous algebraic equations solved once, together, rather than reduced step by step.
FIG: fig28_1.png | Figure 28.1 — A node voltage and the branch currents leaving it: KCL sets currents out equal to currents in.
P: The method treats every node's voltage (relative to a chosen reference node) as an unknown, writes one KCL equation per non-reference node, and solves the resulting system.
H2: 28.2 Choosing a Reference Node
P: Since only voltage differences are ever physically meaningful (Chapter 5), one node in the circuit is designated the reference node, arbitrarily assigned a voltage of exactly 0 V, usually chosen to be the node with the most connections (often literally labeled “ground” on a circuit diagram). Every other node's voltage is then understood to mean its voltage relative to this reference.
H2: 28.3 Writing the Node Equations
P: At every non-reference node, KCL is applied by expressing every branch current leaving that node in terms of the node voltages at its two ends and the resistance of that branch (using Ohm's law, I = V/R, applied across each resistor), and setting the sum of these outgoing currents equal to any current injected into the node by an independent source — one whose value is fixed from outside the circuit, not controlled by anything elsewhere in it:
EQ: Σ (Vnode − Vneighbor) / Rbranch = Iinjected
P: Repeating this for every non-reference node produces a system of linear equations — one equation per unknown node voltage — solvable by substitution, elimination, or matrix methods for larger networks.
H2: 28.4 Handling Voltage Sources: The Supernode
P: An independent voltage source connected directly between two non-reference nodes complicates the ordinary node equation, since the current through a voltage source cannot be written directly in terms of a single resistance the way a resistor's current can. The standard technique is the supernode: the two nodes on either side of such a source are combined into a single “supernode,” for which one KCL equation is written treating the combined current leaving both nodes together, supplemented by a second equation stating the known voltage difference enforced by the source itself. This pair of equations — one KCL equation for the supernode as a whole, one constraint equation from the source — replaces the two individual node equations that would otherwise be needed.
KEY: Nodal analysis produces exactly one equation per unknown node voltage — except at a supernode, which still produces exactly two equations for its two node voltages, though not in the ordinary single-node form. Getting the equation count right before attempting to solve is the fastest way to catch a setup error before it propagates into a wrong final answer.
WE: Worked Example 28.1
PROB: A circuit has two non-reference nodes, A and B. A 10 A current source injects current into node A. A 2.0 Ω resistor connects node A to ground. A 4.0 Ω resistor connects node A to node B. A 5.0 Ω resistor connects node B to ground. Find V_A and V_B.
SOL: Node A: current in (10 A) equals current out through the two resistors leaving A: 10 = V_A/2.0 + (V_A − V_B)/4.0. Node B: current leaving B through its two resistors sums to zero (no source directly at B): (V_B − V_A)/4.0 + V_B/5.0 = 0. Multiplying the first equation by 4.0: 40 = 2V_A + (V_A − V_B), so 40 = 3V_A − V_B. Multiplying the second by 20: 5(V_B − V_A) + 4V_B = 0, so 9V_B = 5V_A, giving V_B = (5/9)V_A. Substituting: 40 = 3V_A − (5/9)V_A = (22/9)V_A, so V_A = 360/22 ≈ 16.36 V, and V_B = (5/9)(16.36) ≈ 9.09 V.
H2: 28.5 Nodal Analysis for Larger Networks
P: For a network with many non-reference nodes, writing and solving the system of node equations by hand becomes impractical past three or four unknowns, and in practice the equations are instead assembled into a matrix equation, GV = I, where G is a conductance matrix built directly from the branch conductances (1/R for each resistor), V is the vector of unknown node voltages, and I is a vector of known injected currents. This matrix, for networks without supernodes, has a simple, mechanical construction rule: each diagonal entry is the sum of conductances connected to that node, and each off-diagonal entry is the negative of the conductance directly connecting the two corresponding nodes. Software tools used throughout the rest of this series (and throughout real engineering practice) build and solve exactly this matrix automatically for networks with hundreds or thousands of nodes — but the underlying equations being solved are never anything more than the same KCL statement introduced in this chapter, applied node by node.
WE: Worked Example 28.2
PROB: A single non-reference node has two resistors, 4.0 Ω and 8.0 Ω, both connecting it to ground, and a 12 A current source injecting current into it. A third resistor, 2.0 Ω, connects this node to a second non-reference node, which itself has only a 6.0 Ω resistor to ground (no other connections). Find both node voltages.
SOL: Let node A be the first node and node B the second. Node A: 12 = V_A/4.0 + V_A/8.0 + (V_A − V_B)/2.0. Node B: (V_B − V_A)/2.0 + V_B/6.0 = 0. Multiplying the node A equation by 8.0: 96 = 2V_A + V_A + 4(V_A − V_B) = 7V_A − 4V_B. Multiplying the node B equation by 6.0: 3(V_B − V_A) + V_B = 0, so 4V_B = 3V_A, giving V_B = 0.75V_A. Substituting: 96 = 7V_A − 4(0.75V_A) = 7V_A − 3V_A = 4V_A, so V_A = 24 V, and V_B = 0.75(24) = 18 V.
MIS: A frequent setup error is writing a node's KCL equation with inconsistent current directions — for instance, treating (V_A − V_B)/R as current leaving node A toward B in one term, while elsewhere in the same equation treating current from a neighboring node as if it were also automatically leaving A. The safest habit is to fix, once and for all before writing anything down, the convention that all resistor currents at a node are written as leaving that node (using the node's own voltage minus its neighbor's, divided by the connecting resistance), with any current source term signed according to whether it injects into or draws out of the node — and then to apply that same convention uniformly to every node equation in the circuit.
BENCH: Choose the reference node sensibly: the node with the most connections, usually the negative supply or the board's 0 V. On the bench, every 'voltage at node X' is relative to wherever your black lead sits, so make your measurement reference the same as your analysis reference.
