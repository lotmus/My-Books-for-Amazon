H1: Chapter 29 — Mesh Analysis
P: Mesh analysis is nodal analysis's twin. Instead of node voltages, you give each window of the circuit its own circulating current. For circuits with many nodes and few loops, it's the shorter road.
P: Where you meet this: Analysis of planar circuits, loop-current thinking about power paths, and ground-loop reasoning in EMC work.
H2: 29.1 The Idea Behind Mesh Analysis
P: Mesh analysis is nodal analysis's mirror image: rather than treating node voltages as the unknowns and applying KCL, it treats loop (“mesh”) currents as the unknowns and applies KVL around each mesh. A mesh, specifically, is a loop that contains no other loop within it — the smallest possible closed paths in a planar circuit diagram, which is why mesh analysis, unlike nodal analysis, applies only to planar circuits (those that can be drawn on a flat page with no branches crossing over one another).
H2: 29.2 Assigning Mesh Currents
P: Each mesh is assigned its own circulating current, conventionally taken clockwise (though any consistent choice works), understood as a fictitious current that flows only around that one mesh's own loop. Where two meshes share a branch, the actual physical current in that shared branch is the difference (or sum, depending on the relative directions) of the two meshes' currents — this is the key bookkeeping idea that makes mesh analysis work, and it is worth drawing out explicitly on a diagram before writing any KVL equation.
H2: 29.3 Writing the Mesh Equations
P: For each mesh, KVL is applied by traversing that mesh's loop in the assumed direction and summing the voltage drops across every element encountered, expressing each resistor's voltage drop in terms of the net current actually flowing through it (which may involve a neighboring mesh's current, for a shared branch), and setting independent sources' contributions on the other side of the equation:
EQ: Σ (Imesh − Ineighbor) Rshared + Σ Imesh Rown = Σ Vsources
P: As with nodal analysis, a current source shared between two meshes complicates the ordinary equation — the analogous fix here is the supermesh: the two meshes on either side of a shared current source are combined into a single supermesh, treated with one KVL equation around the combined outer loop, supplemented by a constraint equation stating the known current relationship the source enforces between the two mesh currents.
KEY: Nodal analysis and mesh analysis are dual methods. Nodal analysis is usually the more efficient choice when a circuit has fewer nodes than meshes (and is especially natural when current sources are involved, since they slot directly into KCL); mesh analysis is usually more efficient when a circuit has fewer meshes than nodes (and is especially natural when voltage sources dominate, since they slot directly into KVL). Both methods, correctly applied, must produce the same final answer for any quantity computed both ways — this agreement is one of the most useful checks available for catching an arithmetic or setup error.
WE: Worked Example 29.1
PROB: A circuit has two meshes. Mesh 1 (current I₁, clockwise) contains a 10 V source and a 2.0 Ω resistor, and shares a 4.0 Ω resistor with mesh 2. Mesh 2 (current I₂, clockwise) contains the shared 4.0 Ω resistor and its own 6.0 Ω resistor, with no independent source. Find I₁ and I₂.
SOL: Mesh 1 KVL (traversing clockwise, starting just after the source): 10 = 2.0I₁ + 4.0(I₁ − I₂), giving 10 = 6.0I₁ − 4.0I₂. Mesh 2 KVL: the shared resistor's drop, from mesh 2's perspective, is 4.0(I₂ − I₁), plus the 6.0 Ω resistor's own drop 6.0I₂, with no source: 0 = 4.0(I₂ − I₁) + 6.0I₂, giving 0 = −4.0I₁ + 10I₂, so I₂ = 0.4I₁. Substituting into the first equation: 10 = 6.0I₁ − 4.0(0.4I₁) = 6.0I₁ − 1.6I₁ = 4.4I₁, giving I₁ ≈ 2.27 A, and I₂ = 0.4(2.27) ≈ 0.91 A. The actual current through the shared 4.0 Ω resistor is I₁ − I₂ ≈ 1.36 A.

H2: 29.4 Source Transformations
P: A practical bridge between nodal and mesh analysis, worth knowing independently of either: any real voltage source in series with a resistance can be replaced by an equivalent current source in parallel with the same resistance, and vice versa, without changing anything about how the rest of the circuit responds — this is exactly the same Thevenin/Norton relationship developed fully in Chapter 30, applied here as a mid-analysis simplification tool. A source transformation can convert a voltage source awkwardly placed for mesh analysis into a current source that slots naturally into a nodal analysis instead (or the reverse), and it is often faster, for a circuit with a mix of source types, to transform every source to whichever type matches the analysis method you intend to use, before writing a single equation.
WE: Worked Example 29.2
PROB: A single mesh contains a 15 V source in series with a 3.0 Ω resistor, forming one branch, connected across a second branch in which a 5.0 Ω resistor and a 2.0 A current source sit in parallel with each other. Use a source transformation on the voltage source and its series resistor to simplify the circuit before analyzing it.
SOL: The 15 V source in series with 3.0 Ω transforms to an equivalent current source of 15/3.0 = 5.0 A in parallel with the same 3.0 Ω resistor. The circuit is now two current sources (5.0 A and 2.0 A) with two parallel resistors (3.0 Ω and 5.0 Ω). Taking both current sources as flowing into the same node (the problem's stated polarities), they add: 5.0 + 2.0 = 7.0 A total. The parallel resistors combine as (3.0)(5.0)/(3.0+5.0) = 1.875 Ω, so the node voltage is V = (7.0)(1.875) ≈ 13.1 V — reached entirely by simple parallel-circuit reasoning, without ever writing a mesh equation.
MIS: Students who have just learned mesh analysis sometimes forget that a resistor shared between two meshes appears in both mesh equations, each time using the difference of the two meshes' currents (with the sign of that difference flipped between the two equations, since each mesh views the same physical current from the opposite side). Omitting the neighboring mesh's contribution to a shared resistor's voltage drop — treating it as if it belonged to only one mesh — is one of the most common setup errors in an otherwise correctly structured mesh analysis, and it is worth double-checking every shared branch specifically for this before solving the resulting system.
BENCH: Thinking in loops pays off far beyond homework. Every current returns to its source, and the loop it takes sets both its magnetic field and its noise pickup. When a measurement is noisy, ask what loop the current is flowing in, and how big that loop is.
