# Working on Lothar's books

Standing rules for every assistant, on any account: **`notes/LOTHAR_RULES.md`**.

Also read `notes/ABOUT_THE_AUTHOR - canonical.md`, `notes/ALSO_BY - canonical list.md`, `notes/HANDOVER.md`, `SCORES.md`, and for science and other nonfiction books `notes/SCIENCE_BOOK_RUBRIC.md` (the scoring rubric). Book-specific notes live in each book's own folder.

To find any book, start with **`notes/BOOK_LOCATIONS.md`**. It lists where every series and single book lives under `D:\My Books for Amazon\`.
