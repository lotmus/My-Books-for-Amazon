# How to use this lesson

Conservation laws have appeared throughout the course, each time as a separate fact: conservation of angular momentum for a central potential (Lesson 14), of probability for the Schrödinger and Dirac equations (Lessons 10 and 24), of charge for the Maxwell equations (Lesson 7). Lesson 5 observed that a cyclic coordinate has a conserved momentum, and Lesson 6 showed that a conserved quantity generates the symmetry to which it belongs. This lesson turns those observations into a general theorem, due to Emmy Noether: to every continuous symmetry of the action there corresponds a conserved current.

The theorem is the reason electric charge is conserved, and the reason it is natural to ask which symmetry a given charge belongs to. It is also the bridge to the rest of the course. The symmetry that yields electric charge is the U(1) phase symmetry of the Dirac field, which Lesson 31 studies, and the demand that this symmetry hold locally, not just globally, produces the interaction of QED (Lesson 39). Expect seven to nine focused hours.

## Learning objectives

- State Noether's theorem for a continuous internal symmetry of a Lagrangian density.

- Derive the conserved current and show that its divergence vanishes on solutions of the field equations.

- Derive the same current a second way, by letting the symmetry parameter depend on position.

- Show that the charge Q = ∫d³x j⁰ is conserved and identify it as the generator of the symmetry.

- Compute the Noether current for the shift symmetry, the U(1) phase symmetry of a complex scalar, and the phase symmetry of the Dirac field.

- Handle symmetries under which the Lagrangian density changes by a total derivative.

- Apply the theorem to spacetime translations and identify the energy density as the time component of the resulting current.

- Explain what the theorem does not give: discrete symmetries, symmetries of the equations that are not symmetries of the action, and the ambiguity in the current.

# 1 Symmetry and conservation

## 1.1 What a symmetry is

A transformation of the fields is a symmetry of the theory if it leaves the action unchanged, or, more precisely, leaves it unchanged for every field configuration, not only for solutions. Two Lagrangian densities that differ by a total derivative have the same action for fields vanishing at the boundary (Lesson 26, Section 2.2), so a transformation is a symmetry if it changes ℒ at most by a total derivative. A continuous symmetry is one that depends on a parameter that can be made arbitrarily small, so that it can be studied to first order in the parameter.

## 1.2 The mechanical prototype

The theorem has a simple particle version that the reader has already met. If the Lagrangian L(q, q̇) does not depend on a coordinate q, then the transformation q → q + ε leaves L unchanged, and the conjugate momentum p = ∂L/∂q̇ is conserved (Lesson 5, Section 4.1). If L does not depend explicitly on time, the transformation t → t + ε leaves the action unchanged and the energy function h is conserved (Lesson 5, Section 4.2). Lesson 6, Section 4.5, added the converse, that the conserved quantity generates the symmetry. Noether's theorem states all of this at once, for any number of coordinates, and, with the same proof, for fields.

# 2 The theorem

## 2.1 Statement

Let the fields φ_a be transformed by φ_a → φ_a + εΔφ_a, with ε an infinitesimal constant. Suppose that for every field configuration, whether or not it solves the equations of motion, the Lagrangian density changes by a total derivative.

$$ δℒ = ε ∂_μ K^μ

Then the quantity

$$ j^μ = Σ_a [∂ℒ/∂(∂_μφ_a)] Δφ_a − K^μ

is conserved on every solution of the field equations: ∂_μj^μ = 0.

## 2.2 Proof

Compute δℒ directly from its dependence on the fields, using the chain rule and δ(∂_μφ_a) = ε∂_μΔφ_a.

$$ δℒ = ε Σ_a [ (∂ℒ/∂φ_a) Δφ_a + (∂ℒ/∂(∂_μφ_a)) ∂_μΔφ_a ]

On a solution of the Euler–Lagrange equations of Lesson 27, ∂ℒ/∂φ_a = ∂_μ[∂ℒ/∂(∂_μφ_a)]. Substituting this for the first term, the two terms combine by the product rule into a single total derivative.

$$ δℒ = ε ∂_μ { Σ_a [∂ℒ/∂(∂_μφ_a)] Δφ_a }

But the symmetry condition says δℒ = ε∂_μK^μ. Equating the two expressions, and dividing by ε, gives ∂_μ{Σ_a[∂ℒ/∂(∂_μφ_a)]Δφ_a − K^μ} = 0, that is ∂_μj^μ = 0.

### Worked example 1

Check the theorem against Lesson 5 for a coordinate that does not appear in the Lagrangian. A particle is a field in zero space dimensions, so the index μ takes only the value 0 and ∂_μj^μ = dj/dt. For L(q, q̇) independent of q, the transformation q → q + ε has Δq = 1 and δL = 0, so K = 0. The current is j = (∂L/∂q̇)Δq − K = ∂L/∂q̇ = p, and dj/dt = 0 says that p is conserved, the result of Lesson 5, Section 4.1.

# 3 A second derivation: a position-dependent parameter

## 3.1 The derivation

The same current can be obtained by a different argument that generalizes to local symmetries. Let the parameter depend on position, ε = ε(x), vanishing outside a finite region. The symmetry condition holds for a constant ε, so it fixes the part of δℒ that involves no derivative of ε. When ε depends on x the only new terms come from ∂_μ(εΔφ_a) = ε∂_μΔφ_a + (∂_με)Δφ_a, so

$$ δℒ = ε ∂_μK^μ + (∂_με) Σ_a [∂ℒ/∂(∂_μφ_a)] Δφ_a

Integrate over spacetime and integrate the first term by parts, using that ε vanishes at the boundary.

$$ δS = ∫ d⁴x (∂_με) { Σ_a [∂ℒ/∂(∂_μφ_a)] Δφ_a − K^μ } = ∫ d⁴x (∂_με) j^μ

The current j^μ appears as the coefficient of ∂_με in the change of the action under a local variation of the symmetry parameter.

## 3.2 Conservation

On a solution of the field equations the action is stationary under every variation of the fields that vanishes at the boundary, and ε(x)Δφ_a is such a variation. So δS = 0 for every ε(x), and integrating by parts once more, 0 = ∫d⁴x (∂_με)j^μ = −∫d⁴x ε ∂_μj^μ. Since ε(x) is arbitrary, ∂_μj^μ = 0, the same result as in Section 2.2. This second derivation shows the logic more clearly: a symmetry means the action is insensitive to a constant ε, and a constant ε extended to a position-dependent ε(x) changes the action only through terms proportional to ∂_με, whose coefficient is the current. It is the version that Lesson 39 will use when the symmetry is made local.

# 4 Examples

## 4.1 The shift symmetry

Consider the massless real scalar field, ℒ = (1/2)∂_μφ∂^μφ, and the transformation φ → φ + ε. Then Δφ = 1 and δℒ = 0, so K^μ = 0. Since ∂ℒ/∂(∂_μφ) = ∂^μφ, the current is

$$ j^μ = ∂^μ φ

and ∂_μj^μ = □φ = 0 is the equation of motion itself. The charge is Q = ∫d³x φ̇. With a mass term, δℒ = −εm²φ is not a total derivative, so the shift is no longer a symmetry and no current is conserved.

## 4.2 The U(1) phase symmetry of the complex scalar

For ℒ = ∂_μφ*∂^μφ − m²φ*φ, the transformation φ → e^(iα)φ with small α = ε gives Δφ = iφ and Δφ* = −iφ*. The Lagrangian density is invariant, so K^μ = 0. With ∂ℒ/∂(∂_μφ) = ∂^μφ* and ∂ℒ/∂(∂_μφ*) = ∂^μφ,

$$ j^μ = ∂^μφ* (iφ) + ∂^μφ (−iφ*) = −i (φ*∂^μφ − φ∂^μφ*)

This is the Klein–Gordon current of Lesson 18, Section 3.1, up to an overall sign that depends on the direction chosen for the parameter: using α → −α, that is Δφ = −iφ, reproduces i(φ*∂^μφ − φ∂^μφ*) exactly. The overall sign of a Noether current is a convention, and it fixes the sign convention for the charge. The interesting point is that the current whose sign problem occupied Lesson 18 is here shown to be the Noether current of a symmetry, and its conservation is a consequence of that symmetry (Exercise 3).

### Worked example 2

Check the two-real-field form of the same symmetry. In terms of φ = (φ₁ + iφ₂)/√2, the phase rotation φ → e^(iε)φ reads δφ₁ = −εφ₂ and δφ₂ = εφ₁, a rotation in the (φ₁, φ₂) plane. Then Δφ₁ = −φ₂, Δφ₂ = φ₁, and with ∂ℒ/∂(∂_μφ_a) = ∂^μφ_a the current is j^μ = −φ₂∂^μφ₁ + φ₁∂^μφ₂ = φ₁∂^μφ₂ − φ₂∂^μφ₁. This agrees with −i(φ*∂^μφ − φ∂^μφ*) computed above, using the relation found in Lesson 25, Exercise 13. If the two fields have different masses, the rotation is not a symmetry and the current is not conserved: ∂_μj^μ = (m₁² − m₂²)φ₁φ₂ (Exercise 4).

## 4.3 The phase symmetry of the Dirac field

Under ψ → e^(iα)ψ, ψ̄ → e^(−iα)ψ̄ with α = ε, the Dirac Lagrangian density ψ̄(iγ^μ∂_μ − m)ψ is invariant, since the phases cancel in every bilinear ψ̄Γψ. Then Δψ = iψ, Δψ̄ = −iψ̄, K^μ = 0. The Lagrangian density has no derivative of ψ̄, and ∂ℒ/∂(∂_μψ) = iψ̄γ^μ (Lesson 27, Section 3.2), so

$$ j^μ = (iψ̄γ^μ)(iψ) = −ψ̄γ^μψ

Again up to the sign convention (Δψ = −iψ gives +ψ̄γ^μψ), this is the current of Lesson 24, and its conservation, derived there by direct manipulation of the Dirac equation, is now seen to be the Noether consequence of the phase symmetry. The charge Q = ∫d³x ψ†ψ is the total number of particles minus antiparticles after quantization (Lesson 36), and multiplying by the charge of the electron gives the electric charge.

## 4.4 A symmetry that changes the Lagrangian by a total derivative

The term K^μ is not always zero. Consider a particle in a uniform force, L = (1/2)q̇² − gq. Under q → q + ε, δL = −gε, which is not zero but is a total time derivative: δL = ε dK/dt with K = −gt. Then Δq = 1, and the conserved quantity is

$$ j = (∂L/∂q̇) Δq − K = q̇ + g t

which is conserved, since q̈ = −g. This is the momentum of a particle in a uniform force, which changes at the constant rate −g, so that q̇ + gt is the constant initial velocity. The translation q → q + ε is a symmetry of the equations of motion in this example, even though it is not a symmetry of the Lagrangian, and the K term is what makes the theorem give the right answer.

### Worked example 3

Apply the theorem to spacetime translations of a scalar field. Under φ(x) → φ(x) + ε^ν∂_νφ(x), with the four parameters ε^ν independent, ℒ changes only through its dependence on the field, so δℒ = ε^ν∂_νℒ = ∂_μ(ε^νδ^μ_νℒ), giving K^μ = ε^μℒ. Taking each ε^ν in turn, Δ_νφ = ∂_νφ and the currents are

$$ T^μ_ν = [∂ℒ/∂(∂_μφ)] ∂_νφ − δ^μ_ν ℒ,    ∂_μT^μ_ν = 0

For ν = 0 and μ = 0 this is T⁰₀ = πφ̇ − ℒ = ℋ, the Hamiltonian density of Lesson 26, Section 3.2. The conserved charge of time translation is therefore the energy, and the conserved charges of the three spatial translations are the components of the momentum. This is the energy-momentum tensor T^μ_ν, developed in full in Lesson 30. The lesson from the example is that the energy of a field, defined in Lesson 25 as a sum over modes, is not an independent definition but the Noether charge of time translation.

# 5 The Noether charge

## 5.1 Conservation of the charge

Define Q = ∫d³x j⁰. Integrating the conservation law ∂_tj⁰ + ∇·j = 0 over all space,

$$ dQ/dt = ∫ d³x ∂_t j⁰ = −∫ d³x ∇·j = −∮ j·dS = 0

where the surface integral vanishes because the fields, and hence j, decay at spatial infinity. The charge is therefore constant in time. This is the argument used for probability in Lesson 10, Section 3.1, and for the Dirac current in Lesson 24, Exercise 8. Lesson 24, Exercise 16 shows in addition that the value of Q is the same on every spacelike slice, so Q is also Lorentz invariant.

## 5.2 The charge generates the symmetry

When K⁰ = 0 and Δφ_a does not depend on the momenta, j⁰ = Σ_aπ_aΔφ_a with π_a the momentum density conjugate to φ_a, and Q = ∫d³x π_aΔφ_a. Using the fundamental bracket {φ_a(x), π_b(y)} = δ_abδ³(x − y) of Lesson 6, Section 7.2,

$$ {φ_a(x), Q} = Δφ_a(x)

so that δφ_a = ε{φ_a, Q}: the Noether charge generates the symmetry transformation through the Poisson bracket, as the momentum generates translations and the angular momentum generates rotations in Lesson 6, Section 4.5. After quantization, the bracket becomes a commutator, [φ_a(x), Q] = iΔφ_a(x), and this is how the charge operator of Lesson 31 will be shown to generate the phase rotations of the field. The theorem of this lesson and the statement of Lesson 6 are two views of the same fact.

### Worked example 4

Verify {φ, Q} = Δφ for the shift symmetry of Section 4.1. Here Δφ = 1 and Q = ∫d³y φ̇(y) = ∫d³y π(y), since π = ∂ℒ/∂φ̇ = φ̇. Then {φ(x), Q} = ∫d³y {φ(x), π(y)} = ∫d³y δ³(x − y) = 1 = Δφ, as required. The charge of the shift symmetry is the total momentum conjugate to φ, and it generates uniform shifts of φ, in the same way that ∫p d³x generates translations of coordinates in ordinary mechanics.

# 6 Remarks and limits

## 6.1 The current is ambiguous

The conserved current is not unique. If A^(νμ) is antisymmetric, ∂_μ∂_νA^(νμ) = 0 by the argument of Lesson 27, Exercise 10, so j′^μ = j^μ + ∂_νA^(νμ) is also conserved. The extra term contributes to the charge only a surface integral, ∫d³x ∂_νA^(ν0) = ∫d³x ∂ᵢA^(i0) (the time derivative term vanishes because A^(00) = 0), which vanishes at infinity, so the charge is unchanged. The ambiguity matters for the definition of local densities such as the energy density, and is the reason there are several energy-momentum tensors in the literature; it does not affect any conserved charge.

## 6.2 On shell and off shell

The symmetry condition δℒ = ε∂_μK^μ must hold for every field configuration, but the conservation ∂_μj^μ = 0 holds only on solutions of the equations of motion. The distinction is essential: the field equations were used in Section 2.2, and a conserved current is a property of the physical, on-shell fields.

## 6.3 Symmetries the theorem does not cover

Noether's theorem requires the transformation to be continuous and to be a symmetry of the action. Discrete symmetries, such as parity and charge conjugation (Lesson 23), have no infinitesimal parameter and produce no conserved current, though they lead to multiplicative quantum numbers. A symmetry of the equations of motion that is not a symmetry of the action gives no current from the theorem: the rescaling φ → (1 + ε)φ of the free scalar field maps solutions to solutions, since the equation is linear, but it changes ℒ by 2εℒ, which is not a total derivative, so the theorem does not apply (Exercise 13).

| Position-dependent parameter gives δS = ∫(∂_με)j^μ | The mechanism by which local gauge invariance forces the introduction of A_μ (Lesson 39) |
| Ambiguity of the current by ∂_νA^(νμ) | The different but equivalent forms of the electromagnetic energy-momentum tensor (Lesson 30) |
| On-shell versus off-shell conservation | Ward identities relate on-shell conservation to relations among Green's functions (Lesson 72) |

The most important entry is the seventh. When the parameter of a global symmetry is allowed to depend on position, the action changes by ∫(∂_με)j^μ, and that is precisely the change that has to be compensated to make the symmetry local. Lesson 39 will show that the compensating term has the form −j^μA_μ, with A_μ shifting by −∂_με/q for a field of charge q so that the covariant derivative ∂_μ + iqA_μ transforms like the field itself, and that this is the QED interaction.

# 8 Summary

1. A continuous symmetry leaves the action invariant, so δℒ = ε∂_μK^μ for every field configuration.

2. Noether's theorem: the current j^μ = Σ_a[∂ℒ/∂(∂_μφ_a)]Δφ_a − K^μ satisfies ∂_μj^μ = 0 on solutions of the field equations.

3. The same current is the coefficient of ∂_με in the change of the action when the symmetry parameter is made position dependent, δS = ∫(∂_με)j^μ.

4. The shift symmetry of the massless scalar gives j^μ = ∂^μφ; the U(1) phase symmetry of the complex scalar gives the Klein–Gordon current; the Dirac phase symmetry gives ψ̄γ^μψ, up to sign conventions.

5. When the Lagrangian changes by a total derivative, K^μ is nonzero and must be included, as in the particle in a uniform force.

6. Spacetime translations give the energy-momentum tensor T^μ_ν, with T⁰₀ equal to the Hamiltonian density.

7. The charge Q = ∫d³x j⁰ is constant in time and Lorentz invariant, and it generates the symmetry through {φ_a, Q} = Δφ_a.

8. The current is ambiguous by a term ∂_νA^(νμ) with A antisymmetric, which leaves Q unchanged; the theorem applies only to continuous symmetries of the action, not to discrete symmetries or to symmetries of the equations alone.

# Solutions

*Attempt each exercise before reading its solution. If you are stuck, read only the first sentence of the solution, then try again.*

**1.** Compute δℒ = ε{(∂ℒ/∂φ_a)Δφ_a + [∂ℒ/∂(∂_μφ_a)]∂_μΔφ_a}, summed over a. On solutions ∂ℒ/∂φ_a = ∂_μ[∂ℒ/∂(∂_μφ_a)], so δℒ = ε{∂_μ[∂ℒ/∂(∂_μφ_a)]Δφ_a + [∂ℒ/∂(∂_μφ_a)]∂_μΔφ_a} = ε∂_μ{[∂ℒ/∂(∂_μφ_a)]Δφ_a} by the product rule. The symmetry condition gives δℒ = ε∂_μK^μ. Equating and dividing by ε, ∂_μ{[∂ℒ/∂(∂_μφ_a)]Δφ_a − K^μ} = 0.

**2.** δℒ = ∂ℒ/∂φ · ε = −εm²φ, since the kinetic term is unchanged by a constant shift. For m ≠ 0 this is not of the form ε∂_μK^μ, because m²φ is not the divergence of any function of the fields alone. The candidate current j^μ = ∂^μφ has ∂_μj^μ = □φ = −m²φ ≠ 0 by the Klein–Gordon equation, so it is not conserved, consistent with the shift not being a symmetry.

**3.** ∂_μj^μ = −i(∂_μφ*∂^μφ + φ*□φ − ∂_μφ∂^μφ* − φ□φ*) = −i(φ*□φ − φ□φ*), since the terms ∂_μφ*∂^μφ and ∂_μφ∂^μφ* are equal and cancel. Using □φ = −m²φ and □φ* = −m²φ*, this is −i(−m²φ*φ + m²φφ*) = 0.

**4.** ∂_μj^μ = ∂_μφ₁∂^μφ₂ + φ₁□φ₂ − ∂_μφ₂∂^μφ₁ − φ₂□φ₁ = φ₁□φ₂ − φ₂□φ₁, the gradient terms cancelling. With □φ_i = −m_i²φ_i this is −m₂²φ₁φ₂ + m₁²φ₂φ₁ = (m₁² − m₂²)φ₁φ₂. It vanishes for all solutions only if m₁ = m₂: the rotation in the (φ₁, φ₂) plane is a symmetry only when the two fields have the same mass, since a mass difference distinguishes the two directions.

**5.** With Δψ = iψ, Δψ̄ = −iψ̄, ∂ℒ/∂(∂_μψ) = iψ̄γ^μ and ∂ℒ/∂(∂_μψ̄) = 0, the current is j^μ = (iψ̄γ^μ)(iψ) = −ψ̄γ^μψ. Then ∂_μj^μ = −[(∂_μψ̄)γ^μψ + ψ̄γ^μ∂_μψ]. From the Dirac equation, γ^μ∂_μψ = −imψ, and from the adjoint equation, (∂_μψ̄)γ^μ = imψ̄, so ∂_μj^μ = −[imψ̄ψ − imψ̄ψ] = 0.

**6.** δL = ∂L/∂q · ε = −gε = ε dK/dt with K = −gt. With Δq = 1, the conserved quantity is (∂L/∂q̇)Δq − K = q̇ + gt. From the equation of motion q̈ = −g, d/dt(q̇ + gt) = q̈ + g = 0.

**7.** Under δq = εq̇ with L having no explicit t, δL = (∂L/∂q)εq̇ + (∂L/∂q̇)εq̈ = ε dL/dt, so K = L. The conserved quantity is (∂L/∂q̇)Δq − K = q̇∂L/∂q̇ − L = h, the energy function of Lesson 5, Section 4.2.

**8.** For ℒ = ∂_μφ*∂^μφ − m²φ*φ, π = ∂ℒ/∂φ̇ = φ̇* and π* = ∂ℒ/∂φ̇* = φ̇. With Δφ = iφ and Δφ* = −iφ*, Q = ∫d³x(iπφ − iπ*φ*). Then {φ(x), Q} = i∫d³y φ(y){φ(x), π(y)} − i∫d³y φ*(y){φ(x), π*(y)} = iφ(x) − 0 = Δφ(x), using {φ(x), π(y)} = δ³(x − y), {φ(x), π*(y)} = 0, and the vanishing of the brackets of φ with φ and φ*.

**9.** dQ/dt = ∫d³x i(∂_tφ∂_tφ* + φ∂_t²φ* − ∂_tφ*∂_tφ − φ*∂_t²φ) = ∫d³x i(φ∂_t²φ* − φ*∂_t²φ). Using ∂_t²φ = ∇²φ − m²φ and the same for φ*, the mass terms cancel and dQ/dt = ∫d³x i(φ∇²φ* − φ*∇²φ) = ∫d³x i∇·(φ∇φ* − φ*∇φ) = i∮(φ∇φ* − φ*∇φ)·dS = 0 for fields decaying at infinity.

**10.** From Lesson 26, Exercise 6, under φ → e^(iε(x))φ, ∂_μφ*∂^μφ → ∂_μφ*∂^μφ + i∂^με(φ∂_μφ* − φ*∂_μφ) + (∂ε)²φ*φ, and the mass term is invariant. To first order in ε, δℒ = (∂_με)i(φ∂^μφ* − φ*∂^μφ). By Section 3.1 with K^μ = 0, δℒ = (∂_με)j^μ, so j^μ = i(φ∂^μφ* − φ*∂^μφ) = −i(φ*∂^μφ − φ∂^μφ*), in agreement with Section 4.2.

**11.** ∂_μj′^μ = ∂_μj^μ + ∂_μ∂_νA^(νμ) = 0 + 0, since ∂_μ∂_ν is symmetric and A^(νμ) is antisymmetric (Lesson 27, Exercise 10). The charge changes by ∫d³x ∂_νA^(ν0) = ∫d³x ∂ᵢA^(i0), because A^(00) = 0 by antisymmetry. By the divergence theorem this is a surface integral of A^(i0) over the sphere at infinity, which vanishes if A^(i0) decays fast enough, so Q′ = Q.

**12.** Noether's theorem is derived for transformations depending on a continuous parameter ε that can be made arbitrarily small, so that the first-order variation δφ = εΔφ exists. Parity is a discrete operation: there is no transformation close to the identity that parity can be built from, so there is no infinitesimal Δφ and no current. A discrete symmetry instead gives a multiplicative quantum number, the eigenvalue ±1 of the parity operator, which is conserved because the operator commutes with the Hamiltonian (Lesson 11, Exercise 14).

**13.** If φ solves the linear equation (□ + m²)φ = 0, so does (1 + ε)φ. But δℒ = ∂ℒ/∂φ εφ + ∂ℒ/∂(∂_μφ)ε∂_μφ = ε(−m²φ² + ∂_μφ∂^μφ) = 2εℒ for the free Lagrangian density (since ℒ = (1/2)∂φ∂φ − (1/2)m²φ² gives φ∂ℒ/∂φ + ∂_μφ∂ℒ/∂(∂_μφ) = 2ℒ). The quantity 2ℒ is not a divergence of a function of the fields for general configurations, so the symmetry condition δℒ = ε∂_μK^μ fails, and the theorem does not apply: this is a symmetry of the equations, not of the action.

**14.** For each pair, ∂_μJ^μ_(ab) = φ_a□φ_b − φ_b□φ_a = (−m²φ_aφ_b + m²φ_bφ_a) = 0 for equal masses, the gradient terms cancelling as in Solution 4. There is one current for each antisymmetric pair, and J_(ba) = −J_(ab), so the independent currents correspond to a < b, which number N(N − 1)/2. These are the currents of the O(N) rotations of the fields; for N = 2 there is one, for N = 3 there are three.

**15.** In four dimensions [φ] = 1 and one derivative adds 1, so j^μ = −i(φ*∂^μφ − φ∂^μφ*) has dimension 1 + 1 + 1 = 3. The volume element d³x has dimension −3, so Q = ∫d³x j⁰ has dimension 3 − 3 = 0, dimensionless, consistent with the charge counting a number of particles.

**16.** With ℒ = (1/2)∂_αφ∂^αφ − (1/2)m²φ², ∂ℒ/∂(∂_μφ) = ∂^μφ, so T^μ_ν = ∂^μφ∂_νφ − δ^μ_νℒ, and raising the index gives T^(μν) = ∂^μφ∂^νφ − g^(μν)ℒ. Then T^(00) = φ̇² − ℒ = φ̇² − (1/2)φ̇² + (1/2)(∇φ)² + (1/2)m²φ² = (1/2)φ̇² + (1/2)(∇φ)² + (1/2)m²φ² = ℋ. For the divergence, ∂_μT^(μν) = □φ∂^νφ + ∂^μφ∂_μ∂^νφ − ∂^νℒ. Using □φ = −m²φ and ∂^νℒ = ∂_μφ∂^ν∂^μφ − m²φ∂^νφ, this is −m²φ∂^νφ + ∂^μφ∂^ν∂_μφ − ∂_μφ∂^ν∂^μφ + m²φ∂^νφ = 0.
