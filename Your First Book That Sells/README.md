# Your First Book That Sells

This folder lives in [lotmus/My-Books-for-Amazon](https://github.com/lotmus/My-Books-for-Amazon). It is not a separate repository. The private repo `lotmus/your-first-book-that-sells` is an unused leftover from an earlier setup. Do not push this book there, and do not turn this folder back into a submodule.

The Kindle manuscript is `First_Review_Kindle_Edition/Your_First_Book_That_Sells_Updated.docx`. `build.py` in that folder is the old generator. It expects local image paths on this PC. Do not replace the docx with an empty file, and do not regenerate it unless those paths exist.

The companion book is a different folder and a different manuscript: `Your First YouTube Channel That Sells/`. Do not merge the two books, and do not copy chapters from one into the other. Agents working on the YouTube book should read that folder’s `CLAUDE.md` and the Current state section of its `_STATUS.md`, then stay there.
