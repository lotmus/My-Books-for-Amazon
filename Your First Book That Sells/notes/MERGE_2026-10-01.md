## Why the "How  to  Pubish…" folder was not in git

Checked 1 October 2026:
1. It sits in `Your First Book That Sells/bak/`, and `.gitignore` ignores `bak/` at every depth. A worker moved it there at 07:44 on 1 October.
2. `Your First Book That Sells/` also contained its own nested `.git` (a separate repo, `lotmus/your-first-book-that-sells`, holding only a placeholder README). With a nested `.git`, the outer repo treats the folder as an embedded repository and stops showing new files in it. That nested `.git` is now `bak/nested-git-your-first-book-that-sells.git`.
3. `info/exclude` holds only `.claude` runtime paths. Not a OneDrive problem.
4. The properly named *How to Publish and Make Good Money* folder existed only on Claude branches and was deleted in `d729653` (28 Sep 2026); it was never on `book-2-lectures-after-qed`.
