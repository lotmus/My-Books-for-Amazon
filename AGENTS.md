# Instructions for Codex and other agents

This repository holds Lothar's books. Read `CLAUDE.md` first (it lists the standing rules and the files to read), then `notes/LOTHAR_RULES.md`, `notes/HANDOVER.md` and, for the children's books by Anneliese Tauber (The Step Stories), `notes/STEP_STORIES_HANDOVER.md`.

Several agents work here at once: pull `origin/main` first, work in a git worktree, never reset the shared checkout `D:\My Books for Amazon`, and commit only the files for the book you are working on. Never print or commit API keys.
