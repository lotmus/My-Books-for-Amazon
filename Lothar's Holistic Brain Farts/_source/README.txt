Lothar's Holistic Brain Farts - source files
Current source snapshot verified 2026-10-15.

The .md files are the text of each section (edit these, not the .docx).
The book is tracked separately from the related Science Sparks manuscript.
To rebuild the Word file after editing (needs Python + python-docx), run
this from the _source folder:

    python build_almanac.py "Lothar's Holistic Brain Farts.docx"

Section order, part titles, bridge paragraphs, foreword and afterword live in build_almanac.py.
The DOCX master sits one folder above _source. On the PC, the project is in
SCIENCE Series\Lothar's Holistic Brain Farts; the GitHub checkout keeps it
beside Science Sparks at the repository root.
