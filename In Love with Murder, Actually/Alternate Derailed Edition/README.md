# Alternate Derailed Edition

An alternate, standalone farce edition of *In Love with Murder, Actually*. This is not the current master manuscript in the parent folder.

- Subtitle: **A Derailed Mystery in Provence**
- Byline: **Lothar J. Musiol writing as Romuald Livingston**
- Source: recovered from commit `469fbb8` and kept as a separate edition so the current master remains untouched.
- Rebuild the Word fallback by running `build_docx.ps1` in this folder. It uses the current book master as a formatting reference and changes only this edition's output.
